# Arduino Rocket Control System

## Overview
This Arduino-based rocket control system is designed to control various components of a rocket launch. The system includes features like a start button to initiate the launch sequence, a reset button to reset the system, and control pins for a fan, LED, rocket lift mechanism, and a Vikram module.

## Features
- Start button for initiating the launch sequence
- Reset button for resetting the system
- Control of a fan and LED during the launch sequence
- Activation of the rocket lift mechanism
- Control of the Vikram module

## Hardware Components
- Arduino board
- Start button
- Reset button
- Fan
- LED
- Rocket lift mechanism
- Vikram module

## Pin Configuration
- Start Button Pin: 8
- Reset Button Pin: 9
- Fan Pin: 11
- LED Pin: 10
- Rocket Lift Pin: 7
- Vikram Pin: 6

## Setup
1. Connect the hardware components according to the specified pin configurations.
2. Upload the provided Arduino code to the Arduino board.
3. Power on the system and use the start and reset buttons to control the rocket launch.

## Usage
- Press the "Start" button to initiate the launch sequence, activating the fan and LED.
- The Vikram module is activated for 3 seconds during the launch sequence.
- Press the "Reset" button to reset the system, activating the rocket lift mechanism for 3 seconds.
